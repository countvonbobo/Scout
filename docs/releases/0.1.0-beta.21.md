# Scout 0.1.0-beta.21

This release fixes a batch of bugs introduced in the beta.20 release that broke several parts of the system when using the new `shortlist` status, as well as fixing issues with CV rendering backup and data corruption.

## Bug Fixes

- **Jobs Pipeline Triage**: Fixed an issue where the pipeline duplicated the triage inbox (Issue #59)
- **Status Propagation**: The `shortlist` status is now correctly propagated across the tracker, scan pipeline, and triage lanes, and all skills have been updated to understand it (Issue #60)
- **Data Corruption (Issue #64)**: Fixed a critical bug where declining a job could corrupt the tracker `opportunities.json` by writing a raw `undefined` token.
- **Archive Tab**: Renamed the "All" tab to "Archive" to serve as the new home for dismissed jobs. Users can now restore dismissed jobs directly from this tab back into the triage inbox (Issue #61)
- **CV Render Self-Healing**: Fixed a bug where a workspace restore could wipe out the CV render manifest, rendering valid PDFs unusable. The UI will now self-heal by checking PDF headers, and prompting for re-render if the source is newer than the PDF (Issue #62).
- **Master CV Rendering Backup**: Fixed a bug where rendering the master CV did not queue a workspace checkpoint, potentially losing the render state across a workspace restore (Issue #62).
